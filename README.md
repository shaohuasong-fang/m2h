# Markdown → 微信公众号排版

一个纯前端的 Markdown 转公众号 HTML 工具：左侧写 Markdown，右侧实时预览，一键复制后可直接粘贴到微信公众号编辑器，样式不会丢失。

所有样式在导出时都会内联到标签上，输出不包含 `class` / `id`，因此不依赖公众号的样式表，也不会被公众号的样式清洗破坏层级。

## 功能特性

- **实时预览**：编辑区输入后自动渲染（120ms 防抖），支持 `.md` 文件拖拽导入与本地自动保存
- **公众号友好**：全内联样式，标题、列表、引用、表格、任务列表、图片、分割线均做了适配
- **macOS 终端风格代码块**：红黄绿三个窗口按钮 + 语言标签；代码换行与空格使用真实 `<br/>` 和 `&nbsp;`，配合 `pre/code` 的 `-webkit-box` + `overflow-x` 结构，长代码在公众号中保持横向滚动、不折行（与 doocs/md 同款方案）
- **语法高亮**：内置 highlight.js 全部语言（193 种），无语言标注时自动识别；额外注册 Oracle PL/SQL 语法，并为 SQL / PL/pgSQL 补充常用关键字
- **50 套科技感标题样式**：经典、霓虹、渐变光带、HUD、编号、终端、代码括号、像素块、双线、缎带、下划线、卡片、等宽极简、发丝线、青蓝、紫光、翡翠、琥珀、玫瑰、钴蓝、双色、虚线、点线、扫描、胶带、标签、瑞士、数据、星云、极地、量子、矩阵绿、霜蓝、曜金、岩浆、深海、樱粉、薄荷、钢铁、石墨、光谱、棱镜、轨道、信号、雷达、线框、角标、刻度、留白、墨黑；H1–H6 全层级联动、字号与间距逐级递减，顶部下拉平铺选择
- **40 种背景纹理**：纯白、网格、点阵、蓝图、斜纹、扫描线、交叉网格、星点、电路板、矩阵、极光、碳纤维、涟漪、三角网格、地平线、极光带、微尘、脉冲、等高线、光晕、六边形、波浪、棋盘、竖纹、霓虹网格、点网、节点、水波、光束、编织、鳞片、准星、像素、星座、蜂窝点、漩涡、天际线、霜纹、熔岩、深海，同样通过平铺下拉选择
- **多种复制方式**：复制到公众号（可视化富文本）、复制 HTML 源码（备用）、下载完整 HTML 文件
- **快捷键**：`Cmd/Ctrl + Enter` 复制到公众号，`Tab` 插入两个空格
- **响应式**：窄屏自动切换为上下布局

## 技术栈

| 用途 | 方案 |
| --- | --- |
| 框架 | Vue 3（`<script setup>` + Composition API） |
| 语言 | TypeScript（`strict` 模式） |
| 构建 | Vite 5 |
| Markdown | marked 12（GFM） |
| 代码高亮 | highlight.js 11 |

项目为纯静态站点，无后端、无环境变量、无数据库。

## 先决条件

### 本地开发

| 依赖 | 版本要求 | 说明 |
| --- | --- | --- |
| Node.js | **≥ 18.18**（推荐 20 LTS 或更高） | Vite 5 支持 Node 18+，建议使用 18.18 以上的 LTS 版本 |
| npm | **≥ 9** | 也可使用 pnpm / yarn，需自行调整锁文件 |
| 现代浏览器 | Chrome / Edge 90+、Safari 15+、Firefox 90+ | 需要支持 Clipboard API 与 `ClipboardItem` |
| 网络 | 可访问 npm registry | 首次安装依赖需要联网 |

检查版本：

```bash
node -v   # 应 >= v18.18
npm -v
```

### 构建与部署

- 已安装上述 Node.js 与 npm，且 `npm ci` 能正常跑通
- 任意静态文件托管服务（GitHub Pages、Netlify、Vercel、Nginx、对象存储等）
- **HTTPS 或 localhost**：浏览器的剪贴板写入接口要求安全上下文；GitHub Pages 默认提供 HTTPS
- 部署产物为 `dist/` 目录，属于纯静态资源，不需要 Node 运行时
- 若部署在**子路径**（如 `https://<用户名>.github.io/<仓库名>/`），必须先在 `vite.config.ts` 中配置 `base`，否则资源会 404

## 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/<你的用户名>/<仓库名>.git
cd <仓库名>

# 2. 安装依赖（推荐用 ci 保证与 package-lock.json 一致）
npm ci

# 3. 启动本地开发服务
npm run dev
# 打开 http://localhost:5173（端口被占用时会自动递增）
```

生产构建与本地预览：

```bash
npm run build    # 先执行 vue-tsc 类型检查，再打包到 dist/
npm run preview  # 本地预览构建产物，默认 http://localhost:4173
```
